# Coral: Evaluation of the Coding Agent

## Advantages

What did using a coding agent make easier, faster, or better in this task?

## Disadvantages

What did using a coding agent make harder, less transparent, or less reliable?

## Oversight and trust

What required human judgment or verification? What agent outputs, if any,
would the group be unwilling to trust without further checking?

## Overall assessment

For which parts of a similar research task would the group use a coding agent
again, and for which parts would it not?
